# 多重启模拟退火揭示的复合地层序列不确定性

**作者**：课程小组成员三  
**单位**：南京大学地球科学与工程学院，江苏 南京 210023

**摘要**：定量地层对比所得复合序列往往并非唯一解，尤其在多剖面化石记录存在缺失、穿时和局部矛盾时，单次最优解难以表达事件位置的不确定性。本文基于 `geology-big-data-hw-main` 项目中的 Python 模拟退火与多重启结果，对南极 Seymour Island 白垩纪-古近纪菊石数据的解空间结构进行分析。项目使用 `scripts/run_multistart.py` 对同一参数组合运行 50 个随机种子，并通过 `scripts/rank_distribution.py`、`scripts/plot_solution_mds.py` 和 `scripts/anchor_judge.py` 分析事件 rank 分布、共识序列、解距离和年龄锚点作用。结果表明，50 个解的 best fit 范围为 238 至 258，Spearman 秩相关最低仍达 0.862，说明解总体结构相似，但局部事件位置具有显著不确定性。Pachydiscus_FAD、Hoploscaphites_LAD 和 KT_EVT 等事件 rank 区间较窄，可视为高置信事件；Anapachydiscus_LAD、Gunnarites_LAD、Baculites_LAD 和 Strontium_ASH 等事件表现出宽区间或双峰分布，指示两个竞争性地层位置。关闭 AGE/ASH 锚点后，5 个随机种子均出现 13 至 17 个锚点顺序错误，说明同位素年龄锚点是构建可信复合序列的必要约束。本文认为，多重启和共识序列分析可将 CONOP 从“寻找一个最优解”扩展为“刻画一组可接受解及其不确定性”。

## Uncertainty of Composite Stratigraphic Sequences Revealed by Multistart Simulated Annealing

**Abstract**: Stratigraphic correlation by constrained optimization may yield multiple acceptable composite sequences. This paper analyzes the solution uncertainty of the Seymour Island ammonite dataset using 50 multistart simulated annealing runs. Rank distributions, consensus sequence, MDS projection and anchor-order experiments show that most solutions share a similar global structure, whereas several events have wide or bimodal rank distributions. Age and ash anchors are necessary constraints because removing them causes severe chronological disorder. Multistart analysis thus changes CONOP interpretation from a single best sequence to an uncertainty-aware ensemble of acceptable solutions.

**Key words**: composite stratigraphic sequence; multistart; uncertainty; consensus sequence; anchor constraint; ammonites

## 1 引言

地层对比的传统表达方式通常是一条确定的综合柱状图或事件序列。然而，在实际资料中，同一化石的首现和末现可能受保存条件、采样密度、生态迁移和剖面缺失影响；不同剖面之间也可能存在局部断层、沉积间断或层位标定误差。因此，复合序列的某些位置可能高度稳定，另一些位置则存在多种可接受排列。

CONOP 模拟退火通过优化 penalty 给出低代价解，但单次运行并不能充分表达解空间。如果不同随机初始序列都收敛到相近排列，说明结果稳定；若若干事件在多次运行中反复落入不同位置，则这些事件应被视为低置信或矛盾事件。本文利用项目中已完成的 50 次多重启实验，讨论如何从解集合中提取共识序列和不确定性信息。

## 2 数据与方法

### 2.1 数据与计算框架

本研究使用的仍是 Seymour Island 白垩纪-古近纪菊石数据，共 12 个剖面、49 个 taxon、22 个 marker 和 120 个复合序列事件。Python 复现版通过 `conop_py/io.py` 解析数据，通过 `conop_py/anneal.py` 执行模拟退火，并通过 `conop_py/incremental.py` 中的 `FastOrdinalState` 加速 ordinal-only 搜索。

多重启实验输出保存在 `results_py/multistart/2026-05-26_190029Z_b-region-test/`。该目录包含 50 个 `bestsoln_s*.dat` 文件、`summary.csv` 和 `manifest.json`。每个 seed 对应一次独立模拟退火运行。

### 2.2 多重启与 rank 分布

对每个解，将 120 个事件按复合序列位置赋予 rank。对同一事件在 50 个解中的 rank 计算中位数、95% 区间和区间宽度，得到 `results_py/rank_distribution/consensus.csv`。rank 中位数可作为共识序列位置，置信区间宽度则反映该事件位置的不确定性。

本方法的优点是直观。若某事件在所有解中位置接近，其 rank 区间窄，代表该事件被多剖面资料稳定约束；若 rank 区间宽或呈双峰，则说明事件可被放在多个相互竞争的位置上。

### 2.3 解距离与 MDS 投影

项目通过 `scripts/plot_solution_mds.py` 计算 50 个解之间的 Spearman 秩相关，并以 `1 - ρ` 作为距离矩阵，再用 MDS 降维到二维平面。该分析用于判断 50 个解是否分裂为若干结构完全不同的解族，还是只在局部事件上存在差异。

### 2.4 锚点裁判实验

AGE 与 ASH 事件带有绝对年龄信息。`conop_py/anneal.py` 中 `build_anchor_order()` 根据权重字段提取同位素年龄锚点，并在 `use_anchors=True` 时强制保持这些 marker 的相对年龄顺序。为判断锚点是否必要，项目使用 `scripts/anchor_judge.py` 关闭锚点约束，对 5 个随机种子运行 Level-only 模拟退火，并检查 18 个锚点事件是否自然保持正确顺序。

## 3 结果

### 3.1 多重启结果显示全局结构稳定但非唯一

50 次重启的 best fit 最小值为 238，中位数约为 250，最大值为 258，标准差约 4.29。与单次运行相比，多重启揭示了同一参数组合下可产生一组相近但不完全相同的解。其分数差距并不大，说明这些解都在可接受范围内；但不同 seed 对若干事件的具体位置判断存在差异。

MDS 投影显示，所有解集中在较小区域内，Spearman 秩相关最低仍达 0.862。这意味着 50 个解没有分裂成完全不同的地层框架，整体复合序列是稳定的。局部不确定性主要集中在少数事件，而不是整个序列发生大尺度重排。

### 3.2 高置信事件与低置信事件

rank 分布结果可将事件分为不同置信等级。项目日志中列出的高置信事件包括 `Pachydiscus_FAD`、`Hoploscaphites_LAD` 和 `KT_EVT`，其 95% rank 区间宽度约为 4 至 5，说明这些事件在 50 个解中的位置高度稳定。K-Pg 界线和若干 LAD 事件的稳定性符合地质预期：区域性灭绝面和年龄锚点通常比局部首现面更容易在多剖面中被一致识别。

相反，`Anapachydiscus_LAD`、`Gunnarites_LAD`、`Baculites_LAD`、`Strontium_ASH`、`Maorites_FAD`、`Phylloceras_(H.)_FAD` 和 `Hypophylloceras_FAD` 等事件的 rank 区间明显较宽。其中若干事件表现为双峰分布，即 rank 不是均匀散开，而是集中在两个相对稳定的位置。这说明算法并非无法判断，而是在两套局部约束之间摇摆。

**表 1 典型事件 rank 不确定性类型**

| 类型 | 代表事件 | 表现 | 解释 |
|---|---|---|---|
| 高置信 | Pachydiscus_FAD | 区间窄 | 多剖面约束一致 |
| 高置信 | Hoploscaphites_LAD | 区间窄 | 末现面稳定 |
| 高置信 | KT_EVT | 区间窄 | 年龄或界线约束强 |
| 双峰矛盾 | Anapachydiscus_LAD | 两个竞争位置 | 局部剖面支持不同排列 |
| 双峰矛盾 | Gunnarites_LAD | 宽区间或双峰 | taxon 延限与其他事件冲突 |
| 宽区间 | Maorites_FAD | 单峰但分散 | 首现面受采样和保存影响 |

### 3.3 FAD 与 LAD 的不确定性差异

从地质意义看，FAD 通常更易受到采样不充分和迁入时间差异影响。某分类单元在某剖面首次被发现，并不一定等于其真实出现时间；缺失下部层位或采样间距大都可能使 FAD 偏晚。LAD 在区域性灭绝或环境事件附近往往更集中，尤其是白垩纪-古近纪界线附近的末现事件，可能更容易形成一致约束。

项目中 rank 分布的现象与此相符：若干 LAD 和 marker 事件区间较窄，而一些 FAD 事件表现为较宽分布。这个结果提示，课堂汇报中可以把“首现面和末现面的不确定性差异”作为地质解释亮点，而不只展示算法图。

### 3.4 锚点约束是必要条件

关闭 `use_anchors` 后，5 个 seed 全部出现锚点顺序错误。错误位置数分别为 15/18、15/18、17/18、14/18 和 13/18。也就是说，菊石相对延限本身不能自然恢复 K-Pg 界线、火山灰层和同位素年龄点的绝对年龄顺序。

这一结果十分重要。若只依赖化石共现和局部层位，模拟退火可能给出低 penalty 但年代上不可信的序列。锚点不是可有可无的附加信息，而是将生物地层序列嵌入绝对时间框架的必要约束。

## 4 讨论

### 4.1 从“最优解”到“可接受解集合”

原版 CONOP 输出一个 best solution，但从多重启结果看，单个 best solution 只是解空间中的一个代表。50 个 seed 产生的解分数接近，说明它们都能较好满足约束；若只报告最低 best fit，可能低估事件位置不确定性。

因此，更合理的表达方式是：用共识序列描述事件的典型位置，用 rank 区间描述置信度，用双峰或宽区间事件识别矛盾热点。这种表达更接近地层资料本身的复杂性，也更适合大数据背景下的定量地层学。

### 4.2 双峰事件的野外意义

双峰 rank 分布代表一个事件存在两个可接受位置。对野外工作而言，这类事件比单纯高 penalty 更有诊断价值。它暗示可能存在以下情况：某 taxon 在不同剖面中的层位关系互相矛盾；某个 marker 与化石事件的相对位置不稳定；或某剖面局部层位记录存在缺失或误差。

例如 `Anapachydiscus_LAD` 和 `Baculites_LAD` 若反复在两个位置之间切换，就可作为后续复查对象。野外可重点检查这些 taxon 在相关剖面中的末现层位、样品编号和剖面厚度标定，而不是平均投入到所有事件。

### 4.3 MDS 结果的解释边界

MDS 投影显示解总体聚集，但二维投影可能放大或压缩高维距离。因此，本文不将 MDS 中的轻微间隙解释为明确的多个地层模式，而只认为它提示局部解簇可能存在。更稳健的结论是：所有解整体结构相似，局部事件存在不确定。

### 4.4 对 PPT 汇报的组织建议

本主题适合作为小组报告的第三部分。可以先展示 50 次多重启 best fit 的分布，再展示 rank violin 图和 MDS 图，最后用锚点裁判实验说明 AGE/ASH 约束的必要性。汇报时应强调：算法不是只给答案，也可以告诉我们哪些地方不确定。

## 5 结论

1. 50 次多重启模拟退火得到的 best fit 范围为 238 至 258，说明同一数据集存在一组分数接近的可接受解。
2. 解之间的整体秩结构相似，Spearman 秩相关最低仍达 0.862，复合序列框架较稳定。
3. 事件 rank 分布揭示了高置信事件和低置信事件。若干 LAD、marker 和 K-Pg 界线事件较稳定，一些 FAD 或局部冲突事件不确定性较高。
4. Anapachydiscus_LAD、Gunnarites_LAD、Baculites_LAD 和 Strontium_ASH 等事件的双峰或宽区间分布，指示存在竞争性地层位置。
5. 关闭 AGE/ASH 锚点会导致 13 至 17 个锚点顺序错误，说明绝对年龄约束是构建可信复合序列的必要条件。
